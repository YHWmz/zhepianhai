- 升级沿用原规则，每批产量 +1、暂存 +3；加工中不能升级。原料、满仓、重复投料均在扣费前校验。加工进度可以保存和恢复。
- “工坊”页查看库存、投料、收取和管理设备；建造菜单新增“基础设备 / 生物工坊”分页，可在空甲板上建造多台。
- 两种循环工坊订单：氧气瓶 3＋树脂 2 换金币 60＋金属 6；氧气瓶 6＋树脂 3 换金币 90＋木材 12＋金属 8。与原商船订单独立，不会让基础经营卡在高级材料上。
- 原十步新手目标后接上七个工坊目标，共 17 个；旧存档新增库存与统计默认从零开始，原进度保留。

## 立即试玩

在本目录运行 `npm start` 或 `node tools/serve.js`，访问 http://127.0.0.1:4173 。无需安装运行时依赖，建议 Node.js 18 或更新版本。服务只绑定本机。

刷新原来的浏览器地址即可更新。原资源、设备、甲板和任务进度保留，旧存档自动补充营地进度，不需要重置。不同浏览器、端口与文件地址的存档相互独立。

## 怎么玩

1. 先点击住宅进入居住改造，拖动木板修屋顶；点击“打捞材料”获得木材、废金属。
2. 点击左侧“过滤器 / 渔场 / 发电机”快捷入口。未建造时进入建造菜单，已有设备时打开管理面板；“待收”区域直接收取。
3. 过滤器每 12 秒产出 2 淡水，渔场每 18 秒产出 1 鱼。投喂电鳗 2 鱼可以发电 3 分钟；在设备面板开启电力加速后生产速度翻倍。
4. 在「家园目标」跟随共 23 项经营目标领取奖励；商船订单提供金币与材料。
5. 点击“居民与营地升级”查看当前居民提出的项目。条件和物资齐备后确认建设，推进营地外观。
6. 打开“居民”页，为三位住户开饭：淡水 2、鱼 1 换生活费 8 金币，间隔 60 秒。完成第一个营地项目后开放，不会离线自动消耗物资。
7. 点击人物看特写、切换人物、体验夸张表情。成功打捞、生产、投喂、交货和营地建设会触发反应。
8. 点击“工坊”进入新生产链；点击“布置甲板”进入工作甲板视图，可建多台设备、扩建和移动。设备升级与电力开关仍在管理面板中。

## 经济与保存

每种资源上限 500；漂流物每 20 秒补 1 份，最多 3 份，每份木材 4、金属 2（完成灯塔后 6、3）。设备暂存满后停止生产。过滤器初始暂存 6，渔场 4；升级每批产量 +1、暂存 +3。电鳗初始容量 3，升级 +1；最多储备 15 分钟燃料。断电只取消加速，基础生产继续。

每次经济操作、每 5 秒与切后台保存。主存档 `tidehaven.save.v1`，备份 `tidehaven.backup.v1`。保持旧版本封装格式并校验新增营地字段；缺少字段的旧存档补默认值。校验和用于发现损坏，不提供防作弊。当前时间与经济在客户端，正式上线需要重新设计可信时间和奖励校验。
