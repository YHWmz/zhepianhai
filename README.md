# 这片海我包了 · v1-plus

海上经营浏览器游戏，包含常驻任务提示、缺料引导、生产倒计时和目标按钮高亮。

## Cloudflare Pages 部署

连接本仓库，选择 Pages（不是 Workers）。

- 生产分支：main
- 框架：None
- 构建命令：`exit 0`
- 构建输出目录：`.`
- 根目录：默认仓库根目录
- 环境变量：无需配置

## 文件说明

`index.html` 是完整的独立静态发布版，包含内嵌的 JavaScript 源代码和图片资源。无外部依赖、无服务端、无密钥，也无需 npm install。可以直接部署或通过本地静态服务器游玩。

存档使用 localStorage，仅保存在当前浏览器当前域名内。从 localhost 换到 Pages 域名不会自动迁移旧存档。换浏览器或清除网站数据也不会保留旧进度。

## 本地预览

安装 Python 3 后，在仓库目录执行 `python3 -m http.server 4191`，访问 http://localhost:4191/。

这是 v1.0.0 的独立任务指引优化版，不包含主工程后续开发内容。未接入微信登录、支付、广告或云存档。
